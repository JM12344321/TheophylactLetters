# Quality Control Checklist

A letter cannot be marked `ready_for_volume` until these checks pass.

## Source

- [ ] Gautier number confirmed.
- [ ] Gautier page and line range recorded.
- [ ] Recipient and normalized name recorded.
- [ ] Date or date range recorded, including uncertainty.
- [ ] PG columns recorded or marked absent.
- [ ] Witnesses recorded from Gautier.
- [ ] Greek text checked against page image or Gautier where OCR is doubtful.

## Translation

- [ ] Every sentence is translated from Greek, not from French or Latin.
- [ ] Supplied English words are bracketed.
- [ ] Difficult syntax is either resolved or noted.
- [ ] Rhetorical repetition is preserved unless impossible in English.
- [ ] Titles and offices are translated consistently.
- [ ] Names and places are normalized without erasing the source form.

## Notes

- [ ] Textual uncertainty is explicit.
- [ ] Biblical citations/allusions are flagged.
- [ ] Classical allusions are flagged.
- [ ] Prosopographical claims cite a source.
- [ ] Historical claims cite a source.
- [ ] Significant alternative interpretations are noted.

## Final audit

- [ ] `source.md` complete.
- [ ] `greek.txt` complete enough to audit.
- [ ] `translation.md` readable and sourced.
- [ ] `notes.md` contains no hidden unresolved problem.
- [ ] `review.md` checkboxes complete.
- [ ] Index row updated.
