# Editorial Policy

## Aim

Produce an English translation that can be checked line by line against the Greek and defended as a scholarly reading edition.

This is not a new critical edition. The project should state that clearly in every volume-level introduction unless a full manuscript collation is actually performed.

## Citation and indexing

- Cite letters by Gautier number first: `G001`, `G002`, etc.
- Add older numbering systems only as cross-references.
- Record Gautier page and line ranges before drafting.
- Record PG columns only where PG contains the relevant letter.
- Use recipient names as Gautier prints them, then add a normalized English form.

## Base text

The translation is made from Greek. Gautier's French translation may clarify how Gautier understood a passage, but it is not the English source.

Where PG/OCR differs from Gautier, record the difference in `notes.md` and translate the reading adopted from the Greek base text.

## Apparatus practice

Use notes for:

- damaged or doubtful readings;
- meaningful variants;
- conjectures;
- names, offices, places, and titles;
- biblical allusions;
- classical allusions;
- legal, fiscal, or ecclesiastical terminology;
- wordplay that cannot be reproduced in English.

Do not bury uncertainty in smooth English. If the Greek is broken, say so.

## Translation style

- Prefer clear, literary English that preserves argument and rhetoric.
- Preserve invective, paradox, repetitions, puns, antitheses, and register shifts when they matter.
- Avoid paraphrase that erases agency, syntax, or theological precision.
- Use square brackets for supplied words.
- Use footnotes or endnotes for source problems, not parenthetical clutter in the translation body.

## Biblical and classical quotations

Translate biblical material from Theophylact's Greek. Do not silently replace it with KJV, NRSV, ESV, or another modern English version.

Mark secure quotations, likely allusions, and generic biblical diction separately.

## Copyright discipline

Gautier 1986 is a modern critical edition. This project records metadata and short working lemmata, not wholesale reproduction of the edition or French translation.
