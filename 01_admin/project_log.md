## Known limits

- The index is intentionally conservative: it contains all Gautier slots but leaves recipient, date, page, line, PG column, and witness metadata blank until checked directly against Gautier CFHB 16/2.
- The project does not include the full Gautier Greek/French text. Use a lawful personal/library copy for collation.
