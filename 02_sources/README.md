Use this folder for source files and provenance notes.

```text

  pg126/

    Patrologia_Graeca_Vol_126.pdf
    extraction_notes.md
  gautier/
    gautier_collation_notes.md
    page_line_map.csv
  secondary/
    mullett_1997_notes.md
    prosopography_notes.md
```

## Source hierarchy

1. Gautier CFHB 16/2 for index, order, boundaries, apparatus, page/line references, recipients, dating, and manuscript evidence.
2. Greek text for translation.
3. PG 126 image/PDF to verify OCR and inherited printed readings.
4. Calfa-GREgORI OCR only as a convenience layer.
5. Secondary works for interpretation, not for replacing the Greek.
